## A1 软件功能
NJGit 是面向游戏开发者的免费 Git GUI 客户端，把版本历史、代码与游戏资产放在同一张工作台上，让每次改动直观看见。

- **游戏资产可视化对比**：直观查看图片、3D 模型与 Unity 场景的前后变化；Unity 场景比较聚焦已保存状态，并标明未还原的内容。
- **代码与历史浏览**：查看文本差异，在仓库、分支、标签、提交记录和变更文件之间连贯浏览。
- **日常 Git 操作**：管理本地变更、暂存与提交，完成 Fetch、Pull、Push。
